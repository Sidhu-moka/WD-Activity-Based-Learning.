## Project Overview
This repository contains three HTML website case studies prepared for the Web Development Activity-Based Learning assignment. The consolidated PDF report includes the supplied browser screenshots, an overview of each project, visible features, implementation notes, and a submission checklist.

### 1. Vinland Electronics Store
An electronics storefront for laptops, smartphones, audio products and smart accessories. Product cards show descriptions, example specifications, ratings, prices and discounts. The page includes search, comparison, offers, contact and cart-related interface elements.

### 2. Vinland Cafe & Restaurant
A cafe website featuring a food menu, chef profiles, restaurant ambience, customer reviews, opening hours/location and a table-reservation form.

### 3. Vinland Shopping Store
A general shopping website featuring electronics, fashion and accessories, category filters, product cards, prices, discount labels, a search box, shopping offers and contact information.

## Technologies
- **HTML5:** Page structure and content
- **CSS3:** Styling, layout, responsive rules, colours, cards and hover effects
- **JavaScript:** Interactive behaviour for controls where the corresponding functions are implemented

## How to Run
1. Download or clone the repository.
2. Keep local assets (for example, `chocolate-icecream.jpg`) at the relative path used by the HTML.
3. Open each HTML file in a modern browser such as Chrome or Edge.
4. Test the layout, navigation, images and interactive controls.
5. If a control does not work, verify that the JavaScript function it calls is implemented in the HTML file or a linked script.
